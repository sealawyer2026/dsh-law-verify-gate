# dsh-law-verify-gate · 法条核验闸门

> AI 法律文书的防幻觉防线 —— 每一条法条引用，逐条比对官方库，实时核验真伪与时效。

**Einstein-OS 出品** · DeepSeek Harness (DSH) 插件

## 它解决什么问题

AI 生成的法律文本里，每一条「《XX法》第X条」都可能是幻觉：不存在的条文、已废止的版本、条号错位——直到它出现在法庭上。

## 四态判决

| 状态 | 含义 | 动作 |
|---|---|---|
| ✅ `verified` | 官方库现行有效 | 直接落稿，附权威原文 |
| ⚠️ `not_found` | 查无此条 | 标注「待核」或删除改写 |
| 🔶 `modified` | 已被修订 | 更新引用版本 |
| 🔶 `expired` | 已失效 | 直接拦下 |

## 双源核验引擎

1. **本地第一道闸**：56,291 条官方法条索引，毫秒级比对，中文数字条号解析（第六百六十七条 → 667）
2. **官方第二道闸**：元典权威智库实时核验时效性，核验结果自动回填本地索引——越用越准

## 工具

- `law_verify` — 对一段文本的所有法条引用执行核验，返回四态判决 + 权威原文
- `law_verify_pricing` — 查询计费方案

## 安装

```bash
dsh plugin --profile <name> add github:<user>/dsh-law-verify-gate
```

前置要求：本机运行 Einstein-OS 法条核验服务（`127.0.0.1:18971`），可用环境变量 `LAW_VERIFY_API` 覆盖地址。
